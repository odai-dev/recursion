A practical algorithmic study in recursive problem solving, divide-and-conquer strategy, and computational complexity analysis in modern JavaScript.

---

## 📐 Implemented Algorithms

### 1. Fibonacci Sequence (`fibonacci.js`)
- **Iterative Approach (`fibs`)**: $O(n)$ time complexity and $O(n)$ space complexity using a loop accumulator.
- **Recursive Approach (`fibsRec`)**: Implements base cases $[0, 1]$ and recursively generates sequence arrays. Demonstrates call stack mechanics and recursion tree dynamics.

### 2. Merge Sort (`merge_sort.js`)
- **Divide-and-Conquer Sorting**: Classic $O(n \log n)$ stable comparison-based sorting algorithm.
- Recursively divides the array into single-element subproblems and merges them back in sorted order using two-pointer merge logic.
